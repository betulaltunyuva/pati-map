# 📖 About

PatiMap is a comprehensive web and mobile platform developed to support the protection and welfare of street animals through modern digital technologies. The platform enables users to report animals in need, monitor reports on an interactive map, and collaborate with volunteers and relevant organizations.

In addition to the reporting system, PatiMap helps users quickly locate the nearest veterinary clinic based on their current location, providing faster access to emergency care for injured or vulnerable animals. The platform also integrates AI-assisted risk analysis to identify high-risk areas and support more effective decision-making.

By combining location-based services, real-time data management, AI-powered analysis, and veterinary guidance in a single platform, PatiMap aims to improve the efficiency of rescue efforts while encouraging community participation in protecting street animals.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/betulaltunyuva/pati-map.git
```

Go to the project directory

```bash
cd pati-map
```

Install dependencies

```bash
flutter pub get
```

Run the project

```bash
flutter run
```
